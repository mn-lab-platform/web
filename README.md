# Mare Nostrum LAB Platform Website

This repository contains the source code for the [Mare Nostrum LAB Platform](https://mn.cenagis.edu.pl/) website. It was written in [Astro](https://astro.build/) and contains all the information you might need about the project, our open-source tools, and the people behind it.

The Mare Nostrum LAB Platform is a part of the wider [Mare Nostrum project](https://mare.id.uj.edu.pl/) at the [Jagiellonian University (JU)](https://www.uj.edu.pl/) in Kraków. 

You can explore all of our open-source tools and customized applications on our [GitHub organization page](https://github.com/mn-lab-platform).

## Built With
- **Framework:** [Astro](https://astro.build/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
